# PRODIGY_DS_02

## Task 02 - Data Cleaning and Exploratory Data Analysis

### Dataset
Titanic Dataset

### Objective
Perform data cleaning and exploratory data analysis (EDA) on the Titanic dataset.

### Data Cleaning
- Filled missing Age values using median.
- Filled missing Embarked values using mode.
- Removed Cabin column.

### Visualizations
1. Survival Distribution
2. Gender Distribution
3. Age Distribution
4. Survival by Gender

### Findings
- Most passengers were aged between 20 and 40.
- Male passengers outnumbered female passengers.
- Female passengers had a higher survival rate.
- More passengers died than survived.
